Сервис управления рассылками

— это веб-приложение для управления рассылками, созданное с использованием Django. Сервис предоставляет возможность создавать письма, рассылать их клиентами, отслеживать попытки рассылок. 
Запуск: Установка и настройка

Клонировать репозиторий
Сначала клонируйте репозиторий с GitHub:

https://github.com/gulnaramari/mailing_service.git 

Создать и активировать виртуальное окружение
